# Atividade Aula 09 - Consultas, índices e relatórios

## Arquivos

- script.sql: criação das tabelas e inserção dos dados iniciais.
- queries.sql: consultas A a F e comandos de inserção e atualização de clientes, pizzas e pedidos.
- index.sql: consultas na tabela Clientes e criação de índice para a coluna nome.
- views.sql: criação de views para consultar pedidos, clientes, pizzas, subtotais e totais.
- README.md: descrição da atividade.

 ## Tecnologias

- MariaDB
- SQL
- Visual Studio Code
